# 旧知识库质量复核

## 背景

知识中心页面截图显示知识总量为138条，但近期已将“精准客户行为诊断法”的7张方法卡和1份原文保真执行模板保存进知识库，因此需要确认这8条内容是否真实存在，以及旧知识是否存在重复、来源不清或质量参差的问题。

本次仅进行了只读核实，没有修改、合并或删除任何知识条目。

## 已确认结论

### 1. “精准客户行为诊断法”8条内容完整

在知识中心搜索“精准客户行为诊断法”，准确返回8条内容：

1. 精准客户视角与诊断前置信息
2. 选题相关性检查
3. 停留与划走点诊断
4. 理解、逻辑与共鸣诊断
5. 需求、信任与买单理由
6. 转化钩子设计
7. 8项检查表总清单
8. 精准客户行为诊断法｜标准执行模板v1

核实结果：

- 7张方法卡和1份执行模板均能正常搜索和显示。
- 每条内容只显示1次，无缺失、无重复。
- 7张方法卡均标明来源为“精准客户行为诊断法·人工确认方法卡”。
- 执行模板标明来源为“精准客户行为诊断法·用户提供文档”。
- 当前均未产生脚本采用记录和发布复盘记录，页面如实显示为0次。
- 这些内容没有冒充“人工确认有效”，当前显示为“未纳入可信度体系”，与保存时约定一致。

清除搜索条件后，知识中心当前显示共146条。截图中的138条与当前数量正好相差8条，因此可以判断：截图反映的是8条内容保存前或页面尚未刷新的状态，不是新内容保存失败、遗漏或被错误隐藏。

### 2. 旧知识库存在真实的重复数据

已发现明确案例：“扮猪吃虎型知识脚本”存在2条同名、高度相似的知识记录。

两条记录虽然措辞和示例略有不同，但核心结构高度一致，均围绕以下方法展开：

- 以懂行顾客与店员的购买对话作为脚本框架。
- 使用“我不要A，因为B，真正应该看C”的表达结构。
- 将消费避坑或选购知识隐藏在真实购买场景中。

搜索“扮猪吃虎型知识脚本”时共返回3条结果，其中：

- 2条为同名、高度相似的方法卡。
- 1条为正文中提及该方法的“知识去重与分层原则”，不属于同名重复记录。

因此，旧知识库中存在真实重复数据已经得到确认，不只是界面显示或搜索命中方式造成的误会。

### 3. 大量旧卡片缺少可信依据

本次抽查的旧卡片包括：

- 内容策划能力目标
- 知识去重与分层原则
- 扮猪吃虎型知识脚本
- 科普／价值观型内容筛选精准人群
- 轻调侃场景型脚本结构
- 反讽共鸣型内容机制
- 关系视角人物塑造法
- 情绪拉回：家人反馈收束

这些卡片具有共同特征：

- 来源统一显示为“智能入库助手”。
- 来源归类为“其他已记录来源”。
- 可信度显示为“未纳入可信度体系”。
- 缺少明确的原始文档、原文章节或外部案例依据。
- 已用于脚本0次。
- 已有发布复盘0次。
- 内容结构完整，但部分结论、适用范围和示例较为概括，尚无真实使用效果支撑。

这些特征说明它们更像早期通过智能入库助手生成的历史方法卡，与近期经过人工逐条审核、保留章节依据的方法卡不属于同一质量层级。

但“缺少来源和效果证据”不等于“内容一定无效”。在没有找到原始材料、没有人工复核之前，不能直接认定它们是测试数据或无价值内容，更不能据此自动删除。

## 建议后续处理

后续单独生成一份“旧知识人工复核清单”，将旧知识逐条归入以下四类：

### 保留

适用于方法清楚、适用边界明确，并能找到可靠来源或真实使用依据的内容。

复核时应记录：

- 原始来源或形成背景。
- 适用场景和不适用范围。
- 是否已有真实采用或发布效果证据。
- 保留理由。

### 疑似重复

适用于标题相同、核心方法相同，或只是换了一种说法的内容。

复核时应并排展示：

- 标题、分类和来源。
- 一句话总结与核心方法。
- 相同点和差异点。
- 建议保留哪一条，以及是否需要人工合并。

系统只提供比较依据，不自动合并或删除，最终由人工确认。

### 来源不足

适用于只有“智能入库助手”等笼统来源，无法追溯到原始文档、完整案例、人工审核记录或其他可靠依据的内容。

这类内容应优先补找来源。暂时找不到来源时，应继续保留“未纳入可信度体系”状态，不得伪装成已经验证的知识。

### 内容过于泛化

适用于表述听起来正确，但缺少明确条件、使用步骤、适用边界或具体依据的内容。

复核重点包括：

- 是否只是在重复常识。
- 是否能指导具体行动。
- 是否明确说明什么情况下适用、什么情况下不适用。
- 是否有足够信息与其他相似卡片区分。
- 是否值得保留为独立知识条目。

## 处理原则

旧知识属于本地知识资产，后续复核和清理必须遵守以下原则：

1. 清理前先对知识库做完整、可恢复的备份。
2. 先生成复核清单，再逐条人工确认。
3. 不根据标题、零使用次数或缺少可信度标记直接删除。
4. 不批量自动合并，不批量自动删除。
5. 疑似重复内容必须展示相同点、差异点和来源，供人工决定保留、合并或删除。
6. 来源不足和内容过于泛化的知识，应先标记问题，不把“待复核”误写成“无效”。
7. 任何删除或覆盖操作都应单独确认，并保留恢复方式和处理记录。
