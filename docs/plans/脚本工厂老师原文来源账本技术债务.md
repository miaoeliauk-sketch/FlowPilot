# 脚本工厂老师原文来源账本技术债务

状态：已记录，暂不实施。以下事项不属于本轮锁恢复P1修复范围，后续必须分别设计、测试和审查。

## 当前部署边界

当前FlowPilot是本机单用户、单个Node服务进程架构，来源账本只承诺同一进程内的请求串行。禁止同时启动两个共享同一账本的FlowPilot服务实例。未来若需要多实例部署，应迁移到SQLite或正式数据库事务；不再扩建心跳、租期、PID判断等文件锁机制。

## 1. 断电级持久化保障

当前账本采用临时文件写入、重命名和回读校验，但尚未对临时文件及父目录执行完整的落盘同步。机器突然断电时，理论上仍可能出现接口已经返回成功、记录却没有稳定保存到磁盘的情况。

后续验收重点：成功响应只能在文件内容和目录变更均完成持久化保障后返回；失败重试不得产生重复来源。

## 2. 来源编号格式严格校验

当前来源编号只校验字符范围和长度，没有严格验证UUID的版本位、变体位等标准格式。损坏账本中的非标准编号可能被误认为合法。

后续验收重点：服务端生成与账本读取使用同一套严格编号解析规则；历史损坏编号必须拒绝使用，不能静默修正。

## 3. 超大请求的流式或前置限流

当前接口会先把完整JSON请求读入内存，再检查老师原文字数。异常大的请求仍可能在被拒绝前占用过多内存。

后续验收重点：在完整载入正文前限制请求体大小；超限请求返回准确错误，且不得创建来源记录或残留临时文件。
