# 专属编导规则部署前提

当前开发环境默认把验证密钥和规则启用状态保存在本机 `data/` 目录，适用于单机开发。

非本地环境启用专属编导规则前，必须同时满足：

1. 配置固定环境变量 `FLOWPILOT_SCRIPT_DIRECTOR_PROOF_SECRET`，长度至少32个字符。不同实例和每次重启必须使用同一个值，且不得提交到Git。
2. `data/script-director-rule-activations.json` 必须位于持久化存储中。当前实现只支持单个服务实例；多实例部署前，需要把启用状态迁移到所有实例共享、支持原子更新的服务端存储。
3. 密钥或启用状态不可用时，生成接口会拒绝使用专属规则，不会静默退化为通用生成。

停用规则会删除服务端当前启用版本。旧启用凭证即使仍留在浏览器中，也不能继续用于生成。
