# 认知解析凭证部署要求

P1 V2认知解析会由服务端签发HMAC凭证，绑定当前IP、Source、原文哈希、AI原始节点和人工审核状态。

非本地环境必须配置固定环境变量：

```text
FLOWPILOT_IP_SOURCE_ANALYSIS_PROOF_SECRET=至少32个字符的随机密钥
```

同一部署每次重启必须使用同一个值。密钥不得提交到Git，也不得返回给浏览器。

本机开发环境未配置时，会在已被`.gitignore`保护的`data/.ip-source-analysis-proof.key`中自动生成仅供本机使用的密钥，文件权限仅当前用户可读写。

审核版本、最终入库状态和老师原文来源记录保存在服务端账本中，账本目录由`.gitignore`保护。当前账本通过单个Node进程内的队列串行处理，只支持单进程实例运行。**禁止同时启动两个共享同一账本的FlowPilot服务实例**，也不支持网络共享目录并发写入。部署时必须使用持久化的本机文件系统；如果未来需要多实例运行，必须迁移到支持事务的SQLite或正式数据库，不能继续扩建文件锁机制，也不能退回由浏览器保存版本号。

历史V1认知不能通过公开接口自行声明迁移资格。运维人员必须先根据已核验的历史备份，在服务端生成`.flowpilot/ledger/ip-source-v1-trusted-migrations.json`，逐条登记`sourceId`、`ipId`、原文SHA-256和认知上下文摘要。登记接口只读该清单，不提供通过浏览器新增白名单的入口；未列入或任一摘要不一致的V1记录均不能获得Legacy凭证。
