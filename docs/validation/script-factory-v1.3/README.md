## 当前状态

- 工程状态：候选版已实现，尚未通过独立盲测。
- 自动测试：2026年8月30日原全量1226项通过；新增跨页面交付守卫4项也通过，生产构建与类型检查通过。
- 独立盲测：未执行。

在盲测材料揭晓并通过前，不得把v1.3标记为正式验证通过。

## 材料边界

产品侧提供材料时应分为两部分：

1. `inputs`：原始素材和待审正文，开发者可以读取。
2. 预期判定：由产品侧独立保管，开发期间不得写入仓库，也不得通过测试名称泄露。

每组输入使用独立编号，不包含真实个人隐私、账号密钥、联系方式或未公开商业数据。

## 结果记录

盲测完成后只记录以下事实：

- 每组实际命中的问题类型；
- 是否绑定了正确正文位置和素材编号；
- 是否出现误报或漏报；
- 人工单次处理后复审的真实结果；
- 未通过项及其原始输出。

禁止修改预期判定来制造“全部通过”。

## 工程映射

- ③冲突书写：生成提示词保留数值和群体表述的原始确定程度；④复审同时检查确定度漂移。
- ④出处审计：现有`/api/script-factory/audit`，新增责任主体失真、仲裁结论无出处和确定度漂移。
- ⑤留白度／装饰细节：当前代码不存在独立⑤阶段，本版不新造接口，不实现“未引入新的感性维度”。
- 重写边界：语义审计失败不再自动改稿；用户只能执行一次人工替换或删除，随后只复审。
